Comment créer un code de réduction Shopify ?

Accédez à Réductions dans votre interface administrateur Shopify, puis ouvrez la page de création d’un code. Le choix suivant dépend de la réduction que vous voulez appliquer.

  1. Ouvrez la section Réductions de l’interface administrateur Shopify.
  2. Choisissez la création d’un code de réduction.
  3. Sélectionnez une réduction d’un certain montant, une offre « Achetez X, obtenez Y » ou l’expédition gratuite.
  4. Choisissez les achats par abonnement, les achats ponctuels ou les deux lorsque cette option est disponible.
  5. Limitez les produits ou la collection si votre code concerne des abonnements précis.

Une réduction d’un certain montant peut prendre la forme d’une valeur fixe. Elle peut aussi prendre la forme d’un pourcentage. Shopify permet de la configurer comme réduction automatique ou comme code.

Quels types de codes de réduction pouvez-vous créer ?

Vous pouvez créer une réduction d’un certain montant, une offre « Achetez X, obtenez Y » ou une réduction pour l’expédition gratuite. Chaque type répond à des règles différentes.

La réduction d’un certain montant s’applique aux produits d’une commande. Elle peut viser les achats par abonnement. Elle peut viser les achats ponctuels. Elle peut aussi viser ces deux types d’achat. Elle ne s’applique pas aux coûts d’expédition.

L’offre « Achetez X, obtenez Y » peut être automatique. Elle peut aussi prendre la forme d’un code. Le produit acheté peut être un abonnement ou un achat ponctuel. Le produit obtenu doit être un achat ponctuel. Cette réduction ne couvre pas les coûts d’expédition.

La réduction pour l’expédition gratuite peut être automatique ou associée à un code. Elle peut concerner les abonnements, les achats ponctuels ou les deux.

Comment limiter un code de réduction sur un abonnement ?

Choisissez le type d’achat et les produits concernés dans la page de création ou de modification de la réduction. L’option Abonnement permet de cibler tous les produits par abonnement. Elle permet aussi de cibler une collection précise. Vous pouvez enfin sélectionner certains produits par abonnement.

Une réduction pour l’expédition gratuite dispose de limites propres aux paiements récurrents. Vous pouvez la limiter au premier paiement. Vous pouvez choisir un certain nombre de paiements. Vous pouvez aussi l’activer pour tous les futurs paiements de l’abonnement.

Un code existant peut être modifié pour inclure des règles fondées sur les abonnements. Vous devez ouvrir la réduction concernée depuis la section Réductions. La rubrique Type d’achat permet ensuite de modifier son périmètre.

Comment cumuler des réductions et générer des codes uniques en masse ?

Une application répertoriée sur Shopify App Store propose le cumul des réductions et la génération de codes uniques en masse. Sa fiche indique que les codes peuvent être générés ou importés. Elle annonce aussi un nombre illimité de codes pour les offres Shopify compatibles.

L’application permet d’exporter les codes au format CSV. Elle suit les revenus, les utilisations et le panier moyen. Elle propose également un audit des expirations, des limites et de l’éligibilité. Ces fonctions appartiennent à l’application décrite sur sa fiche.

Une réduction continue-t-elle après la désactivation du code d’origine ?

Une réduction déjà appliquée à un abonnement est enregistrée dans le contrat sous la forme d’un instantané. Cet instantané reste indépendant du code d’origine. Shopify indique que la réduction continue de s’appliquer lorsque le code d’origine est désactivé ou programmé pour expirer.

Peut-on réserver l’expédition gratuite au premier paiement d’un abonnement ?

Oui, Shopify permet de limiter cette réduction au premier paiement. Vous pouvez aussi sélectionner un certain nombre de paiements. Une autre option applique l’expédition gratuite à tous les futurs paiements de l’abonnement.

Existe-t-il une formule gratuite pour générer des codes en masse ?

La fiche de l’application répertoriée indique qu’un forfait gratuit est disponible. Elle affiche aussi un forfait à 19 $ par mois et un forfait à 99 $ par mois. Un essai gratuit de 10 jours est annoncé pour les forfaits payants présentés. Les frais récurrents et fondés sur l’utilisation sont facturés tous les 30 jours.
