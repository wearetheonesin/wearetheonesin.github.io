Comment créer un code de réduction Shopify ?

Accédez à Réductions dans votre interface administrateur Shopify, puis ouvrez la création d’un code. Choisissez ensuite le type de réduction souhaité.

  1. Ouvrez la section Réductions.
  2. Choisissez la création d’un code de réduction.
  3. Sélectionnez une réduction d’un certain montant, une offre « Achetez X, obtenez Y » ou l’expédition gratuite.
  4. Choisissez les achats par abonnement, les achats ponctuels ou les deux lorsque cette option est proposée.
  5. Sélectionnez les produits ou la collection concernés si vous ciblez des abonnements.

Une réduction d’un certain montant peut correspondre à une valeur fixe. Elle peut aussi correspondre à un pourcentage. Shopify permet de créer un code ou une réduction automatique.

Quels types de codes de réduction pouvez-vous créer ?

Vous pouvez créer une réduction d’un certain montant, une offre « Achetez X, obtenez Y » ou une réduction pour l’expédition gratuite. Chaque type possède ses propres conditions.

L’offre « Achetez X, obtenez Y » ne couvre pas les coûts d’expédition. Elle peut être automatique. Elle peut également prendre la forme d’un code.

Comment limiter un code de réduction sur un abonnement ?

Sélectionnez Abonnement dans la rubrique Type d’achat, puis choisissez les produits concernés. Vous pouvez viser tous les produits par abonnement. Vous pouvez viser une collection précise. Vous pouvez aussi sélectionner certains produits par abonnement.

L’expédition gratuite peut être limitée au premier paiement. Elle peut couvrir un certain nombre de paiements. Elle peut enfin rester active sur tous les futurs paiements de l’abonnement.

Vous pouvez ajouter des règles d’abonnement à un code existant. Ouvrez la réduction concernée depuis la section Réductions. Modifiez ensuite son périmètre dans la rubrique Type d’achat.

Une réduction continue-t-elle après la désactivation du code d’origine ?

Oui, une réduction déjà appliquée à un abonnement reste enregistrée dans son contrat. Cet instantané est indépendant du code d’origine. La réduction continue donc de s’appliquer après la désactivation ou l’expiration programmée du code.

Peut-on réserver l’expédition gratuite au premier paiement d’un abonnement ?

Oui, Shopify permet de limiter l’expédition gratuite au premier paiement. Vous pouvez aussi choisir un certain nombre de paiements. Une autre option couvre tous les futurs paiements de l’abonnement.
